BUSCADOR DE PIEZAS SOLIDWORKS - ALSI
Versión 1.0.7
=====================================

NOVEDADES v1.0.7:
- Migración NAS: Toda la indexación apunta al NAS centralizado (192.168.1.10).
- 4 Orígenes: Proyectos, Biblioteca 3D, ALSI Estándar, ALSI Legends.
- Nuevo Parser: Año inferido desde código de proyecto (sin carpeta AÑO YYYY).
- UI Simplificada: Filtro "Origen" en vez de "Compañeros". Botón único de reindexación.
- Robustez: Document Manager no bloquea indexación si falla.

NOVEDADES v1.0.5:
- UI Pro: Modernización visual completa (macOS/Fluent Design).
- Micro-interacciones: Hover effects, scrollbars compactos.
- Drag & Drop: Arrastra archivos directamente a SolidWorks.
- Panel Preview: Información detallada e iconos por tipo de archivo.
- Indexación Selectiva: Elige qué orígenes actualizar.
- Búsqueda multi-keyword con scoring.

USO:
1. Ejecutar "Buscador de Piezas ALSI.exe"
2. Escribir palabra(s) de búsqueda y pulsar Enter
3. Usar filtros laterales para refinar
